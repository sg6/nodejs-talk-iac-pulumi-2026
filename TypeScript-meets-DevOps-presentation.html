Pulumi's TypeScript building blocks

new Resource(...)

Register a cloud resource with the engine.

new pulumi.Config()

Read configuration for the selected stack.

pulumi.interpolate

Build strings that contain resource outputs.

pulumi.all([...])

Wait for several outputs and combine their values.

output.apply(...)

Transform a value after Pulumi resolves it.

ComponentResource

Package several resources behind one reusable API.
